# Репетитор ЦТ: Английский язык · CT English Tutor

Тренажёр для подготовки к **централизованному тестированию (ЦТ) по английскому языку
в Республике Беларусь** — Android-приложение и Windows-приложение с общим
HTML-интерфейсом (WebView/Edge-окно + Go-хост). Третий самостоятельный предмет этого
репозитория: рядом живут математика и физика, у каждого — свой пакет, ключ подписи,
канал обновления и статистика.

## Что умеет программа

| Требование | Реализация |
|---|---|
| Банк в формате ЦТ | Шесть авторских наборов **2021–2026**, каждый: 18 заданий части A (выбор из пяти) + 22 задания части B (краткий ответ) = 40 заданий, 120 минут** — формат сверен с официальным документом РИКЗ (см. «Источник формата»). Плюс **65 заданий** в тематических пулах для тренировки. Всего **305 заданий** (240 в наборах + 65 тренировочных). Годы — метки наборов в современной структуре, не архивы официальных экзаменов и не исторический формат ЦТ |
| Тренировка и экзамен | Режим тренировки (проверка сразу, разбор, подсказка) и экзаменационный режим (таймер 120 минут, правильность не раскрывается до завершения варианта) |
| Языковая проверка ответа | Отдельный контракт, не числовой: учитываются регистр, артикль, апостроф, дефис, пробел и ударение — ровно так, как требует конкретное задание. Причина отказа называется словом (`case`, `article`, `hyphen`, `space`, `near`…), «почти верно» не принимается за верный ответ, альтернативы допускаются только там, где задание их объявляет |
| Полный разбор ошибки | **76 диагнозов** типичных ошибок (времена, артикли, предлоги, словообразование, «лишнее слово», чтение…): почему так, как исправить, к какому правилу идти, и **сразу однотипные задания** из 39 сгенерированных (`analogous.json`) |
| Правила с бытовыми объяснениями | **13 разделов справочника (14 карточек)**: формулировка, исключения и «как это работает в жизни» — на русском и английском; **5 типизированных схем** (временная ось, дерево решения об артикле, цепочка словообразования, карта предлогов, разбор «лишнего слова») с подписями, доступные офлайн, без CDN и raw SVG |
| Статистика | Прогресс по темам, серии дней, цель на день, история прогонов, разбор ошибок по типам и заданиям — отдельно от математики и физики |
| Обновление контента | Клиент читает релизы **только своей семьи** `english-v*` через GitHub Releases API, отвергает чужой `subject`/`package` и никогда не обращается к общему `/releases/latest/download` (там математика) |
| RU/EN интерфейс | Переключатель языка переводит интерфейс, но **не** проверяемый английский текст: задания всегда остаются аутентичными |
| Автоматические релизы | Каждый доверенный push: сборка контента, parity-векторы, Go-тесты и обе EXE, Kotlin-тесты и подписанный APK, проверка подписи/versionCode «поверх» предыдущего выпуска, публикация `make_latest=false` с audit и суммами |

**Иконка** — речевое облако с «EN» на бирюзовом градиенте (`#3DC9A6 → #116E7A`),
рисуется кодом: `python3 english/tools/make_icon.py` (флаг `--check` сверяет растр и
иконки лаунчера с генератором в CI).

## Источник формата

* `https://result.rikc.by/ru/documents/filesofregpunkts/rce_2025/form__3.pdf`
  (проверено 2026-10-14): **07 Английский язык · АНГ · часть A — 18 заданий,
  часть B — 22 задания, всего 40, 120 минут**.
* Форма за 2026 год на дату проверки отсутствовала (404), поэтому использована
  последняя опубликованная.

Состав частей (открытые разборы и спецификация 2022 года, ссылки в
`../docs/WORKLOG.md`): A — времена, местоимения/артикли/разделительные вопросы,
инфинитив и герундий, фрагменты с ошибкой, лексика, реплики, чтение; B — предлог,
пропущенное слово/фраза, «лишнее слово», словообразование, перевод фрагмента.
Аудирования нет.

## Сборка и проверка локально

```bash
# контент + копии в приложениях
CT_SUBJECT=english python3 english/tools/build_content.py
CT_SUBJECT=english python3 tools/sync_assets.py --check

# проверки предмета
python3 english/tests/test_periods.py
python3 english/tests/test_icon.py
node english/tests/answer_parity.js
node english/tests/content_schema.js
npm install --no-save jsdom && node english/tests/ui_smoke.js

# общая машинерия репозитория (без предметного CT_SUBJECT)
env -u CT_SUBJECT python3 -m unittest discover -s tests -p 'test_*.py'
CT_SUBJECT=english .venv/bin/python tools/check_syntax.py --require

# Windows-хост (нужен Go)
cd english/windows && go test ./... && ./build.sh
```

APK собирает GitHub Actions (`.github/workflows/english-ci.yml`): локально в песочнице
Gradle/Android SDK нет, поэтому «собрано локально» про APK не пишем.

Подробности, состояние приёмки и порядок продолжения — в
[docs/subjects/ENGLISH.md](../docs/subjects/ENGLISH.md).

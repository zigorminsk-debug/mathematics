# Репетитор ЦТ: Русский язык · CT Russian Tutor

Офлайн-тренажёр по русскому языку для централизованного экзамена и централизованного
тестирования (ЦЭ/ЦТ, Республика Беларусь): Android-приложение и Windows-программа с общим
интерфейсом RU/EN.

> **Ветка `arena/339e10e8-mathematics` — отдельное приложение по русскому языку.** В том же
> репозитории живёт «Репетитор ЦТ: Математика» (теги `v…`, ему принадлежит отметка *Latest*).
> Выпуски русского языка — теги **`russian-vГГГГ.М.П`**, они намеренно не помечаются как Latest.

## Скачать / Download

Откройте [Releases](https://github.com/zigorminsk-debug/mathematics/releases) и выберите
самый новый выпуск с тегом `russian-v…` (не тот, что помечен *Latest* — это математика).
Первый выпуск: [russian-v2026.10.1](https://github.com/zigorminsk-debug/mathematics/releases/tag/russian-v2026.10.1).

- **Android:** `app-release.apk` — пакет `by.ziv.ctrussian`, ставится рядом с математикой;
  следующие версии устанавливаются поверх (не удаляйте приложение — удалится статистика).
- **Windows:** `CTRussianTutor-amd64.exe` (обычные ПК) или `CTRussianTutor-arm64.exe`
  (ARM); данные — `%APPDATA%\CTRussianTutor`.

Установка на физический телефон и на Windows агентом **не проверялась** (проверены сборки,
автотесты, мобильный Chromium 393 px и Go-сервер под Linux) — см. `docs/WORKLOG.md`.

## Что внутри

- **Структура по спецификации РИКЗ 2026** (утв. 03.11.2025, <https://rikc.by/ru/specification/2026/01.pdf>,
  сверено 2026-10-14): 40 заданий — часть A 18 (несколько верных из пяти), часть B 22
  (слово, цифры, буквы+цифры), **120 минут**, квоты 9 разделов программы.
- **6 авторских тренировочных вариантов** (2021–2026 — названия наборов, все по структуре
  2026 года; это не официальные материалы РИКЗ) — 240 заданий.
- **54 карточки правил** в 13 областях (фонетика и ударение; лексика, паронимы, фразеология;
  морфемика; корни; приставки, Ъ/Ь, И/Ы; суффиксы и окончания; Н/НН, НЕ/НИ, слитно/дефис;
  морфологические и грамматические нормы; простое и сложное предложение; прямая речь;
  текст): точная формулировка, исключения, бытовое объяснение с оговорками, верные и
  ошибочные примеры, ход рассуждения, нормативные источники, схемы.
- **193 аналогичных упражнения** — не меньше трёх на каждое правило; после ошибки открываются
  карточка и упражнения именно того правила, в котором ошиблись (по неверно выбранным вариантам).
- **Предметная проверка ответов**: пробел, дефис, ё, регистр и ударение — часть ответа;
  лишний выбор не засчитывается; порядок важен только там, где это объявлено.
- 49 офлайн-схем: SVG (ударение, звуки и буквы, морфемный разбор, словообразовательная цепочка,
  грамматическая основа, виды связи, схемы сложных предложений), таблицы противопоставлений
  (HTML) и деревья решений; просмотр с увеличением/сдвигом и возвратом «Назад».
- Экзамен с таймером, тренировка, разбор ошибок, статистика по областям и правилам, отчёт HTML,
  тёмная тема, крупный шрифт, памятки и черновик. Калькулятора и графиков нет — это не математика.

## Разработка

```
python3 tools/build_content.py && python3 tools/sync_assets.py
python3 -m pip install -r requirements-dev.txt
python3 -m unittest discover -s tests -p 'test_*.py'
npm install --no-save jsdom
node tests/answer_parity.js && node tests/content_schema.js
node tests/ui_smoke.js && node tests/native_smoke.js && node tests/rules_smoke.js
```

Подробно: [`AGENTS.md`](AGENTS.md) (передача работы), [`docs/CONTENT.md`](docs/CONTENT.md)
(модель контента и проверки), [`docs/RELEASE.md`](docs/RELEASE.md) (изолированные выпуски),
[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), [`docs/WORKLOG.md`](docs/WORKLOG.md) (журнал).

Каждый проверенный push этой ветки автоматически публикует подписанный APK, обе EXE и банк
заданий как выпуск `russian-v…` — только после успешных проверок контента, Windows и Android.

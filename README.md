# Репетитор ЦТ: Физика · CT Physics Tutor

Тренажёр для подготовки к **централизованному тестированию (ЦТ) по физике в Республике Беларусь** — Android-приложение и Windows-приложение с HTML-интерфейсом, собранные из одного общего ядра (WebView/Edge-окно + Go-хост).

> **Это не обновление математики.** Физика — отдельный предмет с собственным пакетом
> `by.ziv.ctphysics`, собственным каналом выпуска (`physics-v*`, `make_latest=false`) и

> Задания — **авторские тренировочные**, они не являются официальными материалами РИКЗ.

## Что умеет программа

| Требование | Реализация |
|---|---|
| Банк в формате ЦТ | 6 вариантов **2021–2026**: по 10 заданий части A (выбор из пяти) и 20 заданий части B (краткий ответ) = **180 заданий**; формат сверен с перечнем РИКЗ (10 A + 20 B, 210 минут) |
| Тренировка и экзамен | Режим тренировки (проверка сразу и подсказка формулы), экзаменационный режим (таймер 210 минут, без подсказок, навигация по сетке заданий) |
| Проверка ответа как физической величины | Число **вместе с единицей**: `36 км/ч` и `10 м/с` — один и тот же ответ; обыкновенная дробь `1/2`, запись `1,5·10⁶`, `3e8`; ответ `10 Н` на задачу о массе распознаётся как **ошибка размерности**, а не «неточность». Единицы и размерности проверяются по таблице (34 единицы, 10 приставок), без `eval` |
| Полный разбор ошибки | Каталог **52 типовых ошибок** (путаница массы и веса, приставки, забытая единица, неверная размерность…), пошаговое решение, откуда взялась формула, и **сразу открывающаяся тема для изучения** |
| Изучение определений и формул | **37 двуязычных материалов** по 13 разделам: определение, единицы, **условия применимости формулы**, бытовое объяснение с **границами применимости модели**, разобранный пример. **26 графиков и схем** можно увеличить; всё работает офлайн |
| Закрепление | К каждой ошибке подбираются однотипные задания (**39 генераторов** с объяснением используемых констант), кнопка «Закрепить похожими заданиями» собирает отдельный прогон |
| Инструменты | Калькулятор (без `eval`), сборник формул с поиском (**13 разделов, 59 формул**), **справочник единиц** с переводом в СИ, черновик с сохранением по заданию, графики |
| Статистика | Пройденные варианты, точность, время, разбивка по темам и годам, календарь активности, слабые темы с переходом в тренировку, экспорт отчёта в HTML |
| Обновление банка | `tools/build_content.py` проверяет и публикует банк; приложения обновляют его **поверх установленного** из ссылок **своего** выпуска (`physics-v*`) со сверкой SHA-256, прогресс не теряется |
| Подпись постоянным ключом | `android/keystore/ctphysics-release.p12` (алиас `ctphysics`, отпечаток `A3:55:CB:…:83`): новый APK устанавливается **поверх** предыдущего без удаления и без потери статистики |
| Windows на Go | `windows/` — Go (только стандартная библиотека), интерфейс встроен в EXE через `go:embed`, окно открывается в режиме приложения (Edge/Chrome `--app`, отдельный профиль `ctphysics-window`) |
| Автосборка и автопубликация | Каждый push в ветку запускает полный CI; после успеха автоматически публикуются `phyzics.apk`, оба Windows EXE и банк заданий. Номер версии выбирается автоматически, PR/fork не публикуют, выпуск **не переключает** «последний релиз» репозитория (там математика) |
| Языки | Русский ⇄ English одной кнопкой: **213 строк** интерфейса, условия, варианты, подсказки, разборы и отчёт |
| Оформление | Светлая/тёмная тема и три размера шрифта |

## Установка

1. **Android** — скачайте [`phyzics.apk`](https://github.com/zigorminsk-debug/mathematics/releases) из последнего выпуска физики
   (пакет `by.ziv.ctphysics`). Отладочная сборка `app-debug.apk` идёт отдельным артефактом
   и ставится рядом (пакет `by.ziv.ctphysics.debug`).
2. **Windows** — скачайте `CTPhysicsTutor-amd64.exe` (или `arm64` для ARM-устройств) и запустите:
   приложение работает офлайн, прогресс хранится в `%APPDATA%\CTPhysicsTutor` (`--portable` — рядом с EXE).

Проверить целостность загрузки: `SHA256SUMS.txt` в том же выпуске, журнал сборки — `release-info.json`.

## Сборка из исходников

```bash
python3 tools/build_content.py          # проверяет банк, теорию, схемы и генерирует dist/content
python3 tools/sync_assets.py            # копирует интерфейс и банк в android/ и windows/
node tests/answer_parity.js             # Python ↔ JavaScript ↔ Kotlin: одна проверка ответа
python3 -m unittest discover -s tests   # контракт контента, теории, схем и выпуска

cd android && gradle assembleRelease    # phyzics.apk = release/app-release.apk
powershell -ExecutionPolicy Bypass -File windows\build.ps1   # dist\CTPhysicsTutor-amd64.exe
```

Артефакты `app-debug.apk`, `dist/`, `release/` не попадают в репозиторий (см. `.gitignore`).

## Что проверяется автоматически

* `tools/build_content.py` — точная арифметика каждого задания (модель, размерности, домены
  значений), отсутствие чужих предметных слов, полнота RU/EN, границы применимости моделей;
* `tests/answer_parity.js` — 92 единицы и 39 векторов ответов оцениваются одинаково в Python,
  JavaScript и Kotlin, включая **причины отказа** (`empty`, `unit`, `dimension`, `missing_unit`, `value`);
* `python3 -m unittest discover -s tests` — контент, теория, схемы, обновление APK, подпись, план выпуска;
* CI (`ci.yml`) — сборка `phyzics.apk`, подписанного постоянным ключом, обоих EXE и публикация
  выпуска `physics-v*` с `make_latest=false` только из доверенной ветки.

Правила изоляции предметов, формат выпуска и порядок продолжения работы описаны в
[`AGENTS.md`](AGENTS.md) и [`docs/RELEASE.md`](docs/RELEASE.md).
